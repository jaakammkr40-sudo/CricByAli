PREREQUISITES
─────────────
  • Flutter SDK (3.x stable)  →  https://flutter.dev/docs/get-started/install
  • Dart SDK (included with Flutter)
  • Android Studio / VS Code with Flutter extension
  • Android device / emulator  OR  iOS simulator (Mac only)

RUN IN 3 STEPS
──────────────
  1.  Open a terminal in this folder (ClaudeTestNewDev/)

  2.  Install packages:
        flutter pub get

  3.  Launch the app:
        flutter run

      For a specific device:
        flutter devices           ← list connected devices
        flutter run -d <deviceId>

BUILD APK (Android)
───────────────────
  flutter build apk --release
  APK location:  build/app/outputs/flutter-apk/app-release.apk

BUILD IPA (iOS, Mac only)
──────────────────────────
  flutter build ios --release

===========================================================
  TOURNAMENT FLOW
===========================================================

  1. SPLASH  →  3-second animated splash screen

  2. HOME  →  Create Tournament button

  3. SETUP
     • Enter tournament name
     • Set number of teams (2–200)
     • Set number of groups
     • Choose: Auto-generate team names  OR  Type manually

  4. GROUP STAGE
     • Teams shuffled and distributed round-robin into groups
     • Each group runs its own knockout tournament
     • Bye assigned randomly when a group has odd teams
     • Tap a team to mark them as match winner
     • Tap "Next Round" when all matches in a round are done
     • Group winner is the last team standing

  5. KNOCKOUT STAGE  (unlocked when ALL groups finish)
     • All group winners enter the knockout bracket
     • Rounds auto-named: Round of N → Quarter Final → Semi Final → Final
     • Same match interaction as group stage
     • Bye assigned if odd number of winners

  6. WINNER SCREEN
     • Champion name displayed with gold trophy
     • Confetti animation
     • Tournament stats shown
     • "New Tournament" button resets everything
